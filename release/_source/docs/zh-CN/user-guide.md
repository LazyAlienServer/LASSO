# 用户与管理员操作

[目录](README.md) · [English](../en/user-guide.md)

## 普通用户

仅访问运维公布的唯一 HTTPS 通行证站点。`/register` 创建用户名/密码身份，一次显示恢复码；密码至少12字符，登录名3–24位字母/数字/下划线、大小写敏感。离开前将恢复码保存到私有密码管理器/离线位置，不向支持群发送密码、恢复码或恢复输出。产品不要求邮箱/MFA。

`/login` 登录 SSO 通行证；风险控制可能要求验证码/暂等，反复重试会加重问题。业务站通过自己登记的 OIDC 流程接入，不共享密码。必须改密账号先完成强制改密才能普通授权。

| 页面 | 操作及影响 |
| --- | --- |
| `/account` | 查看稳定 ID/资料，改登录名不改变 UUID/业务映射；历史名保留本人，改名间隔90天 |
| `/account/sessions` | 查看/撤销设备会话；撤销/全部退出传播至已接入消费方，当前站退出不结束 SSO 主会话 |
| `/account/recovery-codes` | 查看剩余数量，经近期密码确认换新恢复码；旧批立即失效，新输出只显示一次 |
| `/account/security` | 转至恢复/安全页内改密；按界面提示使旧登录/授权和恢复码状态失效 |
| `/account/authorizations` | 查看/撤销客户端授权；再次授权可能需 consent |
| `/account/delete` | 近期密码/确认后进入30天注销等待；撤销会话、拒服务资格；等待/held期间可取消，执行不可逆 |
| `/password-recovery` | 用户名加未用恢复码/运维人工凭据，设置新密码；本次码消耗，普通恢复后其他未用码仍有效 |

浏览器近期密码证据为15分钟、绑定当前 SSO/浏览器会话，需要时重新输入；refresh 新 Token 不算重输密码。账号注销不承诺自动删除业务站历史内容。怀疑恢复码泄露可安全登录后换新；无可用码联系现有 QQ 群，运维需核实身份并审计一次性人工凭据，联系群不等于身份核验。

## 管理员

SSO 管理员仅管理身份服务，不获得业务站管理员角色。首次任命/重置通过主机离线维护。登录并完成强制改密，敏感写操作需近期密码与可审计原因。

- `/admin/users`：按稳定 UUID/资料查找，查看生命周期/会话/凭据/注销事实；冻结/解冻、撤销会话、经批准人工恢复和支持的管理员交接。确认前核对目标。生命周期限制影响全部消费方，冻结不是 Minecraft 单服封禁；不能用 SQL 绕过最后管理员/转换限制。
- `/admin/clients`：每站/环境独立创建第一方/审核合作方客户端，设置精确 URI/scopes/audience/Back-channel；一次性私密保存 Secret，审查禁用/启用/轮换影响。浏览器变更受门禁保护，Secret 轮换有幂等支持，不代表可日志记录/泄露值。
- `/admin/deletion-requests`：查看 pending/held/history，有原因地 hold/release；held 仍无资格直到解除/取消，不手动删除身份行。
- `/admin/audit`：按时间/action/target 检索，最小化保留脱敏故障证据，不向公开支持渠道发送含个人资料的原始导出。

一次性输出不能通过重开页面找回。失败记录 requestId/时间/类别，按[排障](troubleshooting.md)检查提交状态，避免未经核实反复执行敏感操作。
