# 用户操作：逐项步骤

[目录](README.md) · [English](../en/users.md) · [管理员](administrators.md) · [API](api.md) · [排障](troubleshooting.md)

## 开始前

**执行位置：浏览器，运维公布的唯一SSO HTTPS地址。** 以下路径均相对此地址，不是LASLOG业务站。页面当前按钮为中文，英文手册也保留按钮原文便于对应。先核域名/证书和当前账号名；不在共享屏幕填写密码或展示恢复码。

| 任务 | 流程 |
| --- | --- |
| 创建账号、保存首次恢复码 | U01 |
| 登录、临时密码首次改密 | U02–U03 |
| 编辑资料、修改登录名 | U04–U05 |
| 正常改密、恢复码换批、找回密码 | U06–U08 |
| 撤销设备、退出、撤销应用授权 | U09–U10 |
| 申请/取消注销 | U11 |

密码12–128 Unicode字符且UTF-8不超过512字节，不等用户名、不用内置常见密码。用户名大小写敏感，3–24字母/数字/下划线。SSO管理员身份不等于业务管理员，产品不要求邮箱/MFA。

## U01 注册并保存首次恢复码

**前提：** 你未注册该登录名，并准备好私有密码管理器或离线保管位置。

1. 打开 `/register`；填写用户名、显示名称、密码和确认密码。
2. 完成人机验证，勾选“我会保存下一步显示的一次性恢复码”，点击“创建通行证”。等待结果，避免双击或刷新。
3. 成功后在一次性结果区域选择“复制全部”或“下载文本”；检查保存文件可读，下载目录不是共享/自动外发位置。
4. 勾选“我已安全保存…”确认，再点击“前往登录”。此时仍需用密码登录，注册不会自动登录。

**预期：** 用户创建成功，首次得到10枚恢复码；进入 `/login`。**失败：** 名称占用则换名称；429等待；网络中断先核是否已创建，不反复更换幂等key重注册。已创建但未拿到码：用密码登录，再执行U07，不能重新读取旧码。API幂等重放只返回用户、无码。

## U02 登录与风险提示

**前提：** 当前用户名和密码可用；始终使用同一hostname。

1. 打开 `/login`，按当前用户名原大小写填写，不用UUID或历史用户名替代登录名。
2. 输入密码；个人非共享设备可按页面选择记住设备。管理员会话有独立期限，记住选项不能放宽管理员策略。
3. 点击登录。若要求CAPTCHA，在此页面完成后再提交；若429，按等待提示停止自动重试。
4. 独立账号站成功到 `/account`；业务站发起的登录继续返回该站经验证的回调。若到强制改密页，转U03。

**预期：** 概览显示你自己的用户名及稳定通行证UUID。**失败：** 密码错误/未知账号提示不区分；先核大小写和密码管理器条目，仍无法登录转U08或管理员核验。循环跳转先检查HTTPS、Cookie和hostname，不改为HTTP。

## U03 临时管理员密码首次改密

**前提：** 运维已完成bootstrap，临时密码在24小时有效期内；这里只用于首次激活，不是正常改密。

1. 用运维私密交付的用户名/临时密码登录。
2. 在 `/password-change-required` 填临时密码、新密码及确认密码，点击“更新密码”。此受限会话不能先进入管理页。
3. 看到“密码已经更新”后点“重新登录”，用新密码建立新的登录。
4. 打开恢复码页执行U07并安全保管；运维按需验证管理入口。清除临时密码副本。

**预期：** 旧临时密码/会话失效，新密码可登录，管理员保持唯一。**失败：** 两次新密码不同先修输入；临时密码过期或状态无效由运维执行[离线reset](operations.md)，不改DB哈希。

## U04 编辑显示名称

**前提：** 正常账号登录，不在强制改密/注销受限状态。

1. 在 `/account` 点击“编辑资料”。
2. 修改显示名称（trim后非空、最多64 Unicode字符），点击“保存”。页面只编辑显示名称，并保留已有头像，不提供上传。
3. 页面刷新后核新显示名称及原UUID。

**预期：** 显示名称更新，登录名及UUID不变。**失败：** 400核长度/空值；会话过期重新登录；网络不确定先刷新核现值，避免把重试当新增操作。

## U05 修改登录名

**前提：** 正常登录、知道当前密码，距离上次成功改名满足90天冷却。

1. `/account` 点击“修改用户名”。
2. 填新用户名及当前密码，核大小写和拼写，再点“确认修改”。
3. 概览刷新后核新登录名及原UUID；更新密码管理器的用户名字段。
4. 日后以新名登录。旧历史名仍被占用，但**当前接口拒绝任何已占用历史名，包括本人原名**，不要把页面“本人复用”文字当作当前已实现能力。

**预期：** UUID/身份映射不变，新冷却截止由服务端决定。**失败：** `USERNAME_UNAVAILABLE`换名；`USERNAME_CHANGE_COOLDOWN`按availableAt等待；错密码重填，不能用普通近期认证替代请求里的当前密码。

## U06 正常修改密码

**前提：** 正常登录且持有当前密码。改密会结束已有登录/授权，并使旧恢复材料失效。

1. 打开 `/account/recovery-codes`，点击“修改通行证密码”（`/account/security`会进入相应区域）。
2. 填当前密码、新密码和确认密码，点击“更新密码”。
3. 看到完成提示后点“返回登录”，使用新密码重新登录；不要尝试恢复原会话。
4. 执行U07重新生成并保存恢复码，清旧密码/恢复码副本。

**预期：** 新密码有效，旧登录不可继续；消费方退出通知为异步，实际业务拒绝由该消费方验证。**失败：** 错当前密码401；新密码不可与当前重复/过短/常见。响应丢失：先在正常登录流程核新密码是否已生效，不连续重发改密。

## U07 重新生成恢复码

**前提：** 正常登录，已准备保管新码的位置；确认所有旧码将失效。

1. 打开 `/account/recovery-codes`，先看“可用恢复码”和“最近生成”。这里只能读数量，不能查看旧明文。
2. 勾选“我理解旧恢复码会立即失效”，点击“重新生成恢复码”。
3. 若显示“需要近期认证”，输入当前密码，点击“完成近期认证”；看到成功后**再次点击生成按钮**。认证成功本身不会生成新码。
4. 在“一次性新码”区域复制/下载并检查私有副本，勾选“我已安全保存…”，再离开页面。
5. 删除失效旧批副本；后续重新打开页仅见状态，不重显新码。

**预期：** 新批10枚，旧批废除。**失败：** 无复制权限用下载/手动保存；响应丢失或离页无码：确认当前批状态后有意识再换一批，不期待重开找回。不要为检查而消耗真实码；恢复演练用专用测试账号。

## U08 用恢复码或人工凭据找回密码

**前提：** 当前用户名，以及一枚未用恢复码或经核验私密交付、30分钟内有效的人工凭据。

1. 打开 `/password-recovery`；输入当前用户名和凭据。页面按普通码/人工码识别类型，不要求提供旧密码。
2. 点“验证恢复码”；风险策略要求时完成CAPTCHA并重新提交。
3. 到“设置新密码”步骤后，在10分钟恢复会话内填新密码及确认密码，点击“设置新密码”。验证通过已经消耗本次凭据，不要退出后再用同一枚。
4. 完成后点击“返回登录”，用新密码正常登录。普通恢复同批其他未用码仍有效；若怀疑整批泄漏，再执行U07。

**预期：** 旧密码/会话/授权结束，不自动登录。**失败：** 无效/已用/过期不能复活；10分钟到期需另一枚可用码或新人工凭据。完全无码由管理员执行[人工核验](administrators.md)，不要在群里发送密码/恢复码/Cookie。管理员自身用离线保管材料或运维reset，不能签普通人工恢复凭据给管理员。

## U09 查看设备、撤销与退出

**前提：** 正常登录，先明确要结束的范围。

1. 打开 `/account/sessions`；按设备摘要、最后活动、到期时间和“当前”标识定位，不能仅凭UA摘要判断身份。
2. 撤销其他设备：点击对应行按钮，核确认框，确认。成功后该行消失；该设备需重新登录。
3. 撤销“当前”设备：当前实现会调用**全用户SSO会话/授权退出**，确认前理解这不是只关闭一个标签页。
4. 结束全部设备：使用“退出所有设备…”并确认，成功回登录页。
5. 导航栏“退出通行证”也是SSO用户全局退出。若只退出某业务站，使用该站自己的退出按钮，它应保留SSO主会话。

**预期：** SSO状态结束，适用消费方通知进入投递；不能把按钮成功等同所有离线/不可达BFF已接收。**失败：** 行404先刷新可能已过期；网络不确定先重查，不因队列/网络错误恢复已退出本地登录。

## U10 撤销某应用授权

**前提：** 正常SSO登录；会影响你在该client的全部授权/浏览器，不只一条family。

1. 打开 `/account/authorizations`，核应用名称、client ID、scope及最近使用。
2. 点所选应用“撤销授权”，核对对话框应用名，再点“确认撤销”。
3. 成功后列表删除该应用项；不删除你在其他应用的授权或业务内容。
4. 日后从该应用重新走SSO；合作方可能重新要求consent。退出通知异步投递，目标实际失效另验。

**预期：** 该client下你的授权/consent撤销。**失败：** 超时先刷新列表核结果；业务站旧会话仍可用时交该站负责人核本地新鲜度/Back-channel，不传Token给支持者。

## U11 申请、查看、取消注销

**前提：** 普通账号；管理员不能自助注销。注销不是删除所有业务站历史数据。

1. 打开 `/account/delete`，读30天等待/不可恢复影响，输入当前密码，再点“申请注销通行证”。
2. 成功后原登录失效；若需查看/取消，重新登录，受限会话进入注销页，核requestedAt/executeAfter。
3. PENDING/HELD均不能进入普通账号/业务功能；HELD显示非敏感公开摘要，不表示重新有准入资格。
4. 取消时在同页输入当前密码，点“取消注销申请”；成功刷新为取消/正常状态。旧授权不复活，业务站重新登录。
5. 放任到期执行后身份保留墓碑/用户名约束，不能通过页面或解冻恢复。管理员释放hold保留原执行时间，原期限已过时可很快执行。

**预期：** 申请显示原执行期限及受限状态；取消恢复正常资格，但不复活旧授权。已执行注销不可逆。

**失败：** 网络不确定先查看状态，不另开新key重复申请；账号已执行不可取消；错误密码/CSRF先修当前会话，不改SQL状态。记录时间/requestId和状态，不保存秘密。

## 结果不确定时的统一处理

1. 停止连点，记操作名称、UTC时间、稳定错误code/requestId。
2. 读操作可刷新；写操作先重新查询状态/审计，再决定是否需要一次新的明确操作。
3. 明文丢失按生成/轮换/重发流程；旧秘密不从DB/日志取回。
4. 只把脱敏元信息交支持者；认证、幂等、响应例外见[API](api.md)。
