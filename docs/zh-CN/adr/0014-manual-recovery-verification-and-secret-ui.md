# ADR-0014：人工恢复核验与一次性秘密界面

- 状态：用户在 P04 中确认采用，2026-10-07
- [English](../../adr/0014-manual-recovery-verification-and-secret-ui.md)

## 决策

现有 QQ 群仅联系，不是身份凭据。SSO 管理员签发普通用户人工恢复凭据前，须以既有可信记录核对至少两项独立事实，并记录稳定目标 UUID、依据结论/引用、操作者、原因和结果。公开资料、群成员身份、单一截图、IP 不足；不能核实时不签发。不增加 QQ 登录/绑定、MFA、邮箱或双人审批。

不收集用户密码、恢复码、OAuth Token、完整 Cookie。签发沿用管理员近期密码/原因/审计/一次性/幂等保护，通过已核验的既有私密渠道交付；丢失或交付失败需重发，废旧未用凭据。工单不留明文。管理员使用离线自助码或主机维护，不走普通用户人工签发端点。

一次性人工凭据/client secret 在保存/关闭/Escape/pagehide 时清明文；注册/轮换恢复码离页清理，未确认保存提醒离页并提供保存确认。浏览器剪贴板/下载由用户控制，服务不能保证擦除外部副本。关闭弹窗不能遗留密码值；幂等结果无明文时错误保持可见，不能关闭后丢失恢复指引。

## 后果

人工核验/保管仍由操作者负责，UI 自动测试证明软件行为，不证明真实申请人身份。仅保必要记录引用于受控运维存储，不放公开群/源码。注销争议沿用有界 hold/release/public-summary 和本人取消，管理员不能 SQL 复活 DELETED 或静默取消用户注销。[流程与模板](../operations/manual-recovery-and-lifecycle.md)说明执行步骤。
