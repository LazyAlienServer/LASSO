# 2026-08-09 安全审查修正记录

本轮修正覆盖最近五个账号、注销、审计、人工恢复和 OIDC 客户端管理提交。

## 已修正

- 数据库会话撤销、过期或安全版本失效时，立即清除 Spring Security 上下文并使 HTTP Session 失效。
- 管理员危险写操作统一验证当前数据库角色、活动 `admin_session`、会话安全版本、同源来源和近期认证。
- 注销取消重新验证当前密码；注销后的原会话不能继续使用。
- 注销 Hold 到期任务只更新本批选中的记录，确保每条释放都有安全事件。
- 到期注销遇到管理员提升时取消申请，避免每轮重复处理。
- 删除账号时匿名化显示名并清空头像。
- OIDC 客户端类型严格限制为 `FIRST_PARTY`/`REVIEWED_PARTNER`；生产 Issuer 下拒绝 HTTP 回调。
- Scope/audience 扩大也增加配置版本；不需要撤销的变更同步现有授权版本，避免错误使 RT 失效。
- 注销、管理员用户操作、人工恢复签发和 Client Secret 轮换使用 PostgreSQL 幂等记录；重放不返回一次性秘密。
- 历史用户名不可重新使用，不再改写历史有效期。
- 资料接口支持允许列表头像，并只生成站内头像 URL。
- 人工恢复使用、拒绝、过期和撤销写入关联审计。

## 验证限制

无 Docker 时 PostgreSQL Testcontainers 测试会明确跳过，不再尝试连接开发机固定端口。发布前仍必须在 Docker 可用环境执行零跳过的完整测试，并完成浏览器 E2E。
